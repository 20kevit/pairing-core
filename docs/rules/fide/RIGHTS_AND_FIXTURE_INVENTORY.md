# Rights and fixture inventory

**Inventory date:** 2026-10-27  
**Scope:** source documents, source-derived example data, project-authored synthetic cases, fixture consumers, and generated source views in this repository. This inventory records evidence and disposition; it is not a legal opinion.

## Source documents and copied text

- No full FIDE Handbook chapter, linked PDF, scan, or downloaded source document is committed under `tests/corpus/fide_official/` or the generated evidence pages.
- Source URLs, titles, revision/effective-date statements, retrieval methods/dates, parsed-versus-raw status, checksum status, and supersession pointers are recorded in [`registry/sources.json`](registry/sources.json) and rendered in the [source index](SOURCE_INDEX.md). Current FIDE pages, the C.05 parent/PDF, and the interim-2025 Dutch PDF/Table of Changes (F-0106) were read as parsed content. Original response/PDF bytes were not retained, so no current-source checksum is claimed. The F-0106 Handbook URL returned generic navigation. A reconstruction of the prior abbreviated Council-PDF path without `/DOC/` returned 404, but the prior record does not preserve enough URL text to show that it used that exact path; the correct official Council-PDF URL was subsequently retrieved. These failures do not prove nonexistence. The 404 rights-terms lookup is also not evidence of permission or prohibition.
- F-0106 source identity is now based on the direct official PDF `https://doc.fide.com/docs/DOC/2024%201FC/2024_FC1_TEC_Dutch.pdf` and its Table of Changes. The PDF says “Applied from 1st July, 2025” but prints approval as `dd/mm/yyyy`; no approval date is asserted. F-0105 applies from 2026-02-01, so the registry records 2026-01-31 as the adjacent transition end date and explains that it is not printed in F-0106. Prior PDF/TOCh digests remain historical, unverified records with no retained artifacts. F-0106’s C5/C9 text minimizes the PAB assignee’s score and unplayed games; the source does not categorically exclude every player with fewer games. It is indexed as source-only and is not mapped to either frozen legacy Dutch or Dutch-2026 code.
- A short source wording cue (at most 120 characters), project-authored paraphrases, and source citations appear in the clause views. They are not full source text. No general permission or open licence to reproduce FIDE rule text was identified. Public availability is not treated as redistribution permission.
- The seven remaining JSON files below are project-authored structured data containing factual/numerical values transcribed from, or derived from, official worked examples. Each file says that separate redistribution permission/open licensing for this source-derived data is **not established**. The project owner decided on 2026-10-27 to retain all seven fixtures for now with these warnings; no permission is inferred.

## Disposition of the Lim exchange-table fixture

`tests/corpus/fide_official/lim_exchange_table.json` was removed in this closure wave. It contained a short transcription of the Lim Art. 4.2 opponent-column list. Its only consumer, `test_corpus_lim_tables`, asserted the fixture's stored list against another literal; it did **not** call the pairing implementation. The static assertion was removed, while the source-derived Lim round-one fixture remains. Algorithm behavior is now exercised by project-authored synthetic tests including `test_lim_opponent_column_order_downward` and `test_lim_proposed_pairing_exchanges_around_rematch_in_column_order`. This was judged not to materially weaken implementation coverage. No permission was inferred from its deletion.

## Owner decision recorded; rights evidence still unresolved

Rights for the seven remaining source-derived fixture files are unresolved. Retaining them preserves useful direct regressions against official worked examples but continues redistributing structured source-derived values without recorded permission. Removing/replacing them with synthetic data avoids that redistribution risk but drops official-example comparison coverage.

**Project-owner decision (2026-10-27): retain all seven fixtures for now with the unresolved-rights warnings.** This is a project disposition, not a rights finding: no permission or open licence is claimed. The exact Berger schedules N=3–16 remain because the owner accepted the value of preserving that direct regression pending further evidence. Revisit if permission evidence is obtained or the owner changes this decision.
