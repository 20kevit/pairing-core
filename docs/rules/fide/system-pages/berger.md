# Berger round-robin tables, C.05 Annex 1

**System ID:** `berger`<br>
**System status:** `implemented_for_documented_schedule_scope`<br>
**Sources:** [F-0501](../source-pages/F-0501.md), [F-0502](../source-pages/F-0502.md), [F-0503](../source-pages/F-0503.md)

## Scope and limitations

Generates the published Berger schedule for field sizes 3–16 and supports double-cycle colour swapping. It is a fixed schedule, not a searched Swiss pairing.

**Inspected entry points:** [`src/pairing_core/roundrobin.py::round_robin`](../../../../src/pairing_core/roundrobin.py#L40)

Limitations:
- Official Annex tables cover the recorded range; structural behavior outside that range is not an official-example comparison.
- Reversing the last two rounds in a double round robin is a recommendation exposed as an option, not a mandatory rule.
- C.05 parent §5.1/§5.3 pointers are retained as unresolved prior-wave claims because the parent page fetch exposed no article text; Annex 2 Varma restricted draws are caller-owned and not implemented.
