## Scope and limitations

Pairing algorithm only. Tournament setup, standings, score valuation, result correction and publication remain caller/arbiter responsibilities.

**Inspected entry points:** [`src/pairing_core/fide2026/dutch.py::pair_dutch`](../../../../src/pairing_core/fide2026/dutch.py#L526)

Limitations:
- Exact search has declared deterministic ceilings; exhaustion is a typed failure, not a conformance result.
- C8 look-ahead is limited to the next bracket and is a documented implementation strategy.
- Some rule readings and complete per-system independent verification remain open (G-11).
