# Burstein System, 2026 edition

**System ID:** `burstein-2026`<br>
**System status:** `partial_external_index_required`<br>
**Sources:** [F-0101](../source-pages/F-0101.md), [F-0103](../source-pages/F-0103.md), [F-0110](../source-pages/F-0110.md)

## Scope and limitations

Pairing procedure only. Pairing-Core does not calculate the C.04.4.2 Index. After seeding, the caller must supply a complete, finite, provenance-labelled C.04 Index set; missing values are rejected.

**Inspected entry points:** [`src/pairing_core/fide2026/burstein.py::pair_burstein`](../../../../src/pairing_core/fide2026/burstein.py#L171)

Limitations:
- No local C.04 Burstein Index calculation is implemented.
- C.07 Buchholz/Sonneborn-Berger implementations are not assumed equivalent to C.04.4.2 values or unplayed-round rules.
- The external value producer's semantics and tournament-state correctness remain caller obligations.
