# Lim 2026 — Extracted Rules (C.04.4.3, F-0112)

## Core routing (Art.2)
- 1. PAB = lowest rank in lowest scoregroup (on top of C.04.1 Art.3).
- 2.1 compatibility = unplayed + no 3-in-row + no ±3 imbalance.
- 2.2 median scoregroup = score equal to half rounds played. Order: top ↓ to pre-median,
  then bottom ↑ to median; median LAST, paired downward.
- 2.3 floater triggers: exhausted opponents / ±2 colour no-fix / 2× colour no-alternate /
  odd numbers.
- 2.4 proposed pairings 1v(n/2+1), 2v(n/2+2)… (TPN order, top vs bottom half).
- 2.5 repeat → exchange lower-numbered player (Art.4).
- 2.6 blocked median: compare higher-side vs lower-side floater counts; crack next pairing
  of the float-LIGHTER side… precisely: 2.6.1 higher-count > lower-count → crack LOWER
  pairing, treat as lower floaters, restart; 2.6.2 else crack HIGHER pairing, restart.

## Floater selection (Art.3)
- 3.2.1 direction (down→lower, up→higher). 3.2.2 even-making: pick colour-balancing player.
- 3.2.3 Maxi-tournaments: 100pt rating guard (else lowest/highest numbered).
- 3.2.4 ties: lowest number down / highest number up.
- 3.3 down-choice: lowest-numbered with compatible lower opponent, excluding
  higher-score/number rivals' opponents. 3.4 up mirror.
- 3.5 incompatible floater: swap within group if possible, else float further.
- 3.6 higher-side order: highest score (then number); multi-group → highest group;
  DF before UF in upper/median. 3.7 lower-side mirror (lowest score/number; UF before DF
  in lower half).
- 3.8 partner: highest-available alternate-colour (down) / lowest-available (up);
  Maxi 100pt guard. 3.9 hierarchy a–d (re-floated+no-partner > re-floated+partner >
  fresh+no-partner > fresh+partner); avoid a, then b, then c.
- 3.10 previous-round floater not re-floated for even-making unless it avoids a/b/c or
  preserves pair count.

## Exchanges (Art.4) + colours (Art.5) + last round (Art.6) + R1/R2 (Arts.7–8)
- 4.1 scrutiny: downward from highest number (exchange LOWER-numbered), upward from
  lowest (exchange HIGHER-numbered). 4.2/4.3 worked 6-player tables (1v4→1v5→…
  columns given). 4.4 float-on-failure incl. #7-swap / pair-float rules.
- 5.1 alternate + even-round equalisation; hard bans 3-in-row (5.1.1), ±3 (5.1.2).
  5.2 double scrutiny (novelty then colours). 5.3 2×-same-colour must alternate
  (float if incompatible). 5.4 history walkback; identical histories → median-split:
  above/median higher-ranked gets alternate (equalising on even), below lower-ranked.
  5.5 odd rounds ≤1 imbalance. 5.6 even rounds level (shared-equaliser → history
  decides, +2 tolerated once). 5.7 Maxi guard.
- Art.6 last round: same-score duty overrides colours (even 3×/±3).
- Art.7 R1: odd → lowest-rated PAB; #1 colour by lot; odd upper-half follow #1,
  evens oppose; worked 40-player tables; only lot-decided colours.
  Art.8 R2: groups by score; order 1pt → 0pt → 0.5pt (median last).
