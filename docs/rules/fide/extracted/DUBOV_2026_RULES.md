Goal [Preface]: equalise ARO within scoregroup — low-ARO players meet high-rated opponents.

## Definitions
- 1.1 ratings MANDATORY (provisional assigned by Chief Arbiter if missing).
- 1.2 TPN per C.04.2; recalculated on pre-round-4 rating changes.
- 1.3 bracket = residents + LOWER upfloaters; NO downfloaters (closed).
- 1.6 preferences as Dutch, except zero-game = mild Black (differs from Dutch 1.7.4!).
- 1.7 ARO = mean of played-opponents' ratings, round half-up, zero if unplayed, recomputed after each round.
- 1.8 maximum upfloater: already upfloated MaxT = 2 + floor(Rnds/5) times.
- 1.9 outlook: PAB first, then top-down; C1–C3 absolute; else Arbiter decides.

## Criteria C1–C10
C1 no repeat; C2 PAB block; C3 same-absolute shall not meet (NO topscorer carve-out —
stricter than Dutch); C4 completion; C5 minimise upfloaters; C6 minimise upfloater-pair
score gaps (= maximise upfloater scores asc); C7 colours granted; C8–C10 (non-last-round):
minimise max-upfloaters used / repeat max-upfloat usage / previous-round upfloat reuse.

## Procedures
- 3.1 PAB: eligible (C2) → completion-enabling (C4) → lowest score → most games →
  largest TPN. Legal pairing = C1+C3+C4 (3.2.1 note).
- 3.2.1 minimum upfloaters for legality; 3.2.2 first upfloater set (4.2 order) with best
  C1–C10 (higher-priority quality first).
- 3.2.3 G1 = White-seekers (or TPN top-half if nobody played); G2 = rest.
- 3.2.4 shift unavoidable same-subgroup pairs, then equalise sizes; best = first set
  (4.3 order) yielding best C7-compliant legal pairing.
- 3.2.5 S1 = G1 sorted by ARO asc, then TPN asc. 3.2.6 first T2 (4.4 order) yielding
  legal pairing, paired 1–1, 2–2….
- Art.4: pool → primary-key sequence numbers → K-sets by smallest differing number;
  upfloaters keyed score-desc/TPN-asc; White shifters ARO-asc else TPN, Black shifters
  TPN-asc, middle-outward numbering (worked A–G example); G2 transpositions keyed TPN-asc.
- Art.5 colours: unplayed-vs-unplayed odd-TPN higher-ranked takes initial-colour;
  both → stronger → alternate (C.04.2 3.4) → higher-ranked preference.
