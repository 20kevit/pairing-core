# Burstein 2026 — Extracted Rules (C.04.4.2, F-0110)

Goal [Preface]: equalise ratings-free Index within scoregroup — high-Index meets low-Index.

## Definitions
- 1.2 bracket = residents + incoming floaters from previous bracket.
- 1.5 preferences as Dutch (zero-game = none).
- 1.6 seeding: first min(floor(R/2),4) rounds use DUTCH rules.
- 1.7 opposition evaluation: Buchholz = current scores of faced opponents;
  SB = Σ points-earned × opponent current score (wins + half draws under standard scoring);
  unplayed round = self-game with registered result; consecutive zero-bye streaks =
  draws for opponents' benefit; virtual (acceleration) points EXCLUDED.
- 1.8 ranking = Index (Buchholz, then SB), then TPN asc. Scores NOT used.
- 1.9 outlook: PAB first, top-down; C1–C3 absolute.

## Criteria C1–C8
C1/C2 as Dutch; C3 same-absolute barred (no topscorer carve-out); C4 completion;
C5 max pairs (= minimise outgoing floaters); C6 minimise outgoing-floater scores desc;
C7 next-bracket C1–C6; C8 colours granted.

## Procedures
- 3.1 PAB: eligible → completion → lowest score → most games → lowest Art.1.8 rank
  (differs from Dubov's largest-TPN tiebreak!).
- 3.2.1 max pairs under C1–C5 (fixes outgoing-floater count); 3.2.2 first pairing
  (Art.4 order) with best C1–C8.
- Art.4: BSNs in 1.8 order; pad with zero-BSN virtual floaters (= outgoing count);
  pairings ordered by BSN#1's opponent BSN descending, then #2…, with full worked
  6-player/2-pair enumeration table (normative example).
- Art.5 colours mirror Dubov with Art.1.8 rank key.
