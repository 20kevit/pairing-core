# Code of Conduct

Be professional: assume good faith, critique work (not people), keep
discussion evidence-based and on-topic, respect scope decisions made by the
owner. Harassment, discrimination, or repeated bad-faith relitigation of
closed decisions is not acceptable.

Violations: contact the repository owner via a private GitHub Security
Advisory or direct message. The owner may warn, temporarily restrict, or
permanently remove participants. This is a small engineering project; the
goal is a proportional response, not bureaucracy.
